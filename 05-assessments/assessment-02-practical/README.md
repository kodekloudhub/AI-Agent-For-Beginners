# Assessment 2 - Practical Build

A single-file build that assembles everything from the course: a bounded
agent loop, safe tool dispatch, injection detection, output redaction,
persistent memory, and a run summary.

`assessment_agent.py` is the completed reference solution. The lab ships
a starter version with five `TODO TASK` blocks that students fill in - in
the KodeKloud environment the starter is written to
`/root/code/assessment_agent.py` by the lab's startup script.

## Run

```bash
pip install openai
python assessment_agent.py "Book a meeting called Standup on Monday"
```
